# Security policy

EH3D-PHOENIX-PCB is at its first steps. If you find a vulnerability, or an instruction that could make somebody run something on a machine without its limits, please report it.

## Reporting a problem

Please report it privately to **electrohobby3d@gmail.com**, with what you found and where. Do not open a public issue for it. You will get an answer as soon as possible; this is a one-person project.

Only the latest version is supported.

The review of security that the project made of itself, with its limits and what it does not cover, is in [docs/SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md). It is not an external audit.

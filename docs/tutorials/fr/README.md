# Tutoriels

## Comment exécuter les tutoriels

Exécutez chaque commande depuis la racine du dépôt. Les commandes n'écrivent que de nouveaux fichiers ou un nouveau dossier dans `build/`, que vous créez d'abord avec `mkdir build` ; rien d'existant n'est remplacé. La sortie montrée est le début de ce que chaque commande affiche. Les blocs qui commencent par `# test` sont exécutés par les tests du dépôt, qui comparent le début de la sortie (une ligne qui commence par `~` doit apparaître quelque part dans la sortie). Tous les outils de ce programme sont des prototypes qui n'ont pas été comparés à un outil de référence.

L'aide est dans le programme : `phoenix help` liste les thèmes et les commandes, `phoenix help sim` et `phoenix help --lang es sim` expliquent un thème ou une commande.

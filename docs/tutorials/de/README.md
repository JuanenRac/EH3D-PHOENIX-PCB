# Anleitungen

## So führen Sie die Anleitungen aus

Führen Sie jeden Befehl im Hauptordner des Repositorys aus. Die Befehle schreiben nur neue Dateien oder einen neuen Ordner in `build/`, den Sie zuvor mit `mkdir build` anlegen; nichts Vorhandenes wird ersetzt. Die gezeigte Ausgabe ist der Anfang dessen, was der Befehl ausgibt. Die Blöcke, die mit `# test` beginnen, führen die Tests des Repositorys aus und vergleichen den Anfang der Ausgabe (eine Zeile mit `~` am Anfang muss irgendwo in der Ausgabe vorkommen). Alle Werkzeuge dieses Programms sind Prototypen, die nicht mit einem Referenzwerkzeug verglichen wurden.

Die Hilfe steckt im Programm: `phoenix help` listet Themen und Befehle auf, `phoenix help sim` und `phoenix help --lang es sim` erklären ein Thema oder einen Befehl.

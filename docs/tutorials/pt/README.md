# Tutoriais

## Como executar os tutoriais

Execute cada comando a partir da raiz do repositório. Os comandos só escrevem ficheiros novos ou uma pasta nova dentro de `build/`, que se cria antes com `mkdir build`; nada do que existe é substituído. A saída mostrada é o início do que cada comando imprime. Os blocos que começam por `# test` são executados pelos testes do repositório, que comparam o início da saída (uma linha que começa por `~` tem de aparecer algures na saída). Todas as ferramentas deste programa são protótipos que não foram comparados com uma ferramenta de referência.

A ajuda está no próprio programa: `phoenix help` lista os temas e os comandos, `phoenix help sim` e `phoenix help --lang es sim` explicam um tema ou um comando.

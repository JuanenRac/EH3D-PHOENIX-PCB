# Guías de funciones

## Cómo ejecutar las guías

Ejecute cada comando desde la raíz del repositorio. Los comandos solo escriben ficheros nuevos o una carpeta nueva dentro de `build/`, que se crea antes con `mkdir build`; nada de lo que existe se reemplaza. Las guías muestran los comandos y describen lo que contiene la salida. Los bloques que empiezan por `# test` los ejecutan las pruebas del repositorio, que comparan el comienzo de la salida (una línea que empieza por `~` tiene que aparecer en algún lugar de la salida); los demás comandos no se ejecutan y no citan ninguna salida, así que lea la salida real con la guía al lado. Todas las herramientas de este programa son prototipos que no se han comparado con una herramienta de referencia.

# EAGLE の回路図のバスを読み込む

`examples/guides/bus.sch` は最初のチュートリアルの回路図に、シート上のバス `D[0..1]` と、配線がバスの線上で終わる 2 本のネット `D0`、`D1` を加えたものです。読み込み時にバス名がメンバーを持つバスオブジェクトになり、各ネットがバスに出会う位置にエントリが置かれます。バスは名前の付け方であり、メンバーは普通のネットです。

コマンドはリポジトリのルートで実行します。[ガイドの実行方法](README.md) を参照してください。

1. 階層を JSON で読みます。キー `buses` はシートのバスの数で、1 です。両方のメンバーがエントリで使われているので、問題の一覧に `PHOENIX-BUS` 系のコードはありません。

```console
# test
$ phoenix hier --json examples/guides/bus.sch
~ "buses": 1
```

2. 同じ内容をテキストで見ます。ネットの一覧には 2 本以上のピンをつなぐネットだけが載るので、ここでは `MID` だけです。ピンを持たないバスのメンバー `D0` と `D1` は載りません。最後の行に問題の有無が出ます。

```console
# test
$ phoenix hier examples/guides/bus.sch
~ nets:
~ MID
```

3. 回路図を KiCad のファイルとして書き出します。バスはそのラベルと、アンカーからエントリの端を通る線として、各エントリはメンバーのラベルを持つ `bus_entry` として書かれます。

```console
$ phoenix kicad-export --out build/bus.kicad_sch schematic examples/guides/bus.sch
```

## 結果の読み方

* ベクタ `接頭辞[最初..最後]` は `接頭辞<最初>` から `接頭辞<最後>` までのメンバーになります（`D[0..1]` は `D0` と `D1`。`A[2..0]` のように下がる向きも可）。EAGLE のリスト（`A[0..3],B[0..3]`）や、コロン付きの名前（`BUS:A[0..3]`、コロンの前がバス自体の名前）も読めます。
* バスは最初の線が始まる位置にアンカーされます。メンバーの名前を持ち、バスの線上で終わるシート上の各ネットの端にエントリが作られます。バス自身の線やラベル、ベクタでない名前、線のないバスは読まれず、省かれた部分として数えられます。コード `PHOENIX-BUS-001` から `PHOENIX-BUS-007` がバスの問題を示し、`phoenix hier` が一覧します。

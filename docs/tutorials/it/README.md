# Tutorial

## Come eseguire i tutorial

Eseguite ogni comando dalla radice del repository. I comandi scrivono solo nuovi file o una nuova cartella dentro `build/`, che create prima con `mkdir build`; nulla di esistente viene sostituito. L'output mostrato è l'inizio di ciò che ogni comando stampa. I blocchi che iniziano con `# test` sono eseguiti dai test del repository, che confrontano l'inizio dell'output (una riga che inizia con `~` deve comparire da qualche parte nell'output). Tutti gli strumenti di questo programma sono prototipi non confrontati con uno strumento di riferimento.

La guida è nel programma: `phoenix help` elenca i temi e i comandi, `phoenix help sim` e `phoenix help --lang es sim` spiegano un tema o un comando.

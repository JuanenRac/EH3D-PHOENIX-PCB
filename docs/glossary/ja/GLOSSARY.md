# 用語集

このプログラムで使われる分野の用語です。英語ページ末尾の表に、各用語の 8 言語表記があります。

| 用語 | 意味 |
|---|---|
| **nm（ナノメートル）** | モデル内のすべての長さの単位で、整数として保持します。1 mm は 1 000 000 nm なので、加算や比較に丸め誤差がありません。 |
| **ネット** | 電気的に接続されるべきパッド・配線・ビアの集まりで、GND のような名前を持ちます。 |
| **ネットクラス** | 配線幅・クリアランス・ビアサイズなどのルールを共有するネットのグループです。第 2 形式のルールファイルがクラスを保持します。 |
| **ビア** | 2 つの層の銅箔をつなぐめっき穴です。 |
| **アニュラリング** | 穴の周囲に残る銅箔のリングです。細すぎると、ドリルで破れることがあります。 |
| **フットプリント** | 基板上の部品の銅パッド、穴、図形です。 |
| **コートヤード** | フットプリントの周囲で、他の部品が入ってはいけない領域です。 |
| **銅箔ゾーン** | 塗りつぶされた銅箔領域（通常はグランドプレーン）で、他のネットとのクリアランスを保ちます。 |
| **層構成** | 基板の銅層と絶縁層の順序・厚さ・材料です。線路のインピーダンスはこれで決まります。 |
| **DRC（デザインルールチェック）** | 最小配線幅、クリアランス、穴径、アニュラリングなどの制限に対する基板の検査です。コマンド：`phoenix check`。 |
| **ERC（電気ルールチェック）** | 回路図の検査です。どのネットにも属さないピン、誰も駆動しない入力、電源のない供給などを調べます。コマンド：`phoenix erc`。 |
| **ラッツネスト（未配線ライン）** | まだ配線されていない接続を示す直線です。コマンド：`phoenix ratsnest`。 |
| **Gerber X2** | 製造業者が読む銅箔・ソルダーマスク・ペースト・シルクのファイル形式です。X2 は層の機能などの属性を追加します。 |
| **Excellon** | ドリルファイルの形式で、工具と穴の位置（めっきの有無）を記します。 |
| **DSN / SES** | 外部オートルータ用の Specctra ファイルです。DSN は渡す設計、SES は配線結果を含んで戻るセッションです。コマンド：`phoenix autoroute`。 |
| **Vカット** | パネル内の 2 枚の基板の間に直線状に入れる溝で、折って分離できるようにします。 |
| **パネル（面付け）** | 複数の基板を 1 枚にまとめ、フレーム、タブ、フィデューシャル、工具穴を付けて、一度に製造・実装できるようにしたものです。コマンド：`phoenix panel`。 |
| **ミシン目タブ（マウスバイト）** | 2 枚の基板の間のタブに小さな穴を一列に並べ、きれいに折れるようにしたものです。 |
| **フィデューシャルマーク** | 実装機が基板の位置を知るために見る、裸銅の小さな丸いマークです。 |
| **実装位置データ（ピックアンドプレース）** | 実装機のための、各部品のリファレンス・位置・回転・実装面を記したファイルです。コマンド：`phoenix pnp`。 |
| **メタルマスク（ステンシル）** | 開口部からはんだペーストをパッドに塗布するための薄い板です。コマンド：`phoenix stencil`。 |
| **BOM（部品表）** | 基板の部品を値とフットプリントでまとめ、数量と価格を付けた一覧です。コマンド：`phoenix bom`。 |
| **差動ペア** | 電圧の差で 1 つの信号を伝える 2 本の配線です。間隔、等しい長さ、対称性を保つ必要があります。コマンド：`phoenix pairs`。 |
| **クロストーク（NEXT、FEXT）** | 信号の一部が隣の配線に現れる現象です。近端（NEXT）はドライバ側、遠端（FEXT）は反対側で見えます。コマンド：`phoenix si crosstalk`。 |
| **S パラメータ／Touchstone** | 各周波数でのネットワークの反射と伝送です。Touchstone（.s1p、.s2p）がそれを保存するファイルです。コマンド：`phoenix rf touchstone`。 |
| **VSWR（電圧定在波比）** | 1 以上の数で、負荷が線路にどれだけ整合していないかを表します。1 が完全な整合です。 |
| **モンテカルロ** | 許容差の範囲で値をランダムに変えながら回路を多数回実行する手法です。シードを固定すれば毎回同じ表になります。 |
| **ネットリスト** | 回路の素子と、それらが結ぶノードを並べたテキストで、シミュレータが読むものです。コマンド：`phoenix netlist`。 |
| **ドライラン** | 書き込み以外のすべてを行う実行で、書き込まれる・変更される内容を表示します。`--out` が新しいファイルを指さない限り、ほとんどのコマンドはドライランです。 |

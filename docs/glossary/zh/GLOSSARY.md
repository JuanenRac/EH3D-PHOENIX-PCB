# 术语表

本程序所用的领域术语。英文页面末尾的表格给出了每个术语的八种语言写法。

| 术语 | 含义 |
|---|---|
| **nm（纳米）** | 模型中所有长度的单位，以整数保存：1 mm 等于 1 000 000 nm，因此加法和比较没有舍入误差。 |
| **网络** | 必须在电气上相连的所有焊盘、走线和过孔；它有 GND 这样的名称。 |
| **网络类** | 共用线宽、间距和过孔尺寸等规则的一组网络。第二种格式的规则文件保存这些类。 |
| **过孔** | 连接两层铜箔的金属化孔。 |
| **焊环** | 钻孔周围留下的铜环；太窄时钻头可能把它破坏。 |
| **封装** | 元件在电路板上的铜焊盘、孔和图形。 |
| **占位区（courtyard）** | 封装周围不允许其他元件进入的区域。 |
| **铜区** | 填充的铜区，通常是地平面，与其他网络保持间距。 |
| **叠层** | 电路板铜层和绝缘层的顺序、厚度与材料；线路的阻抗取决于它。 |
| **DRC（设计规则检查）** | 按最小线宽、间距、钻孔和焊环等限值检查电路板。命令：`phoenix check`。 |
| **ERC（电气规则检查）** | 对原理图的检查：不在任何网络上的引脚、无人驱动的输入、没有电源的供电等。命令：`phoenix erc`。 |
| **飞线（ratsnest）** | 用直线显示哪些连接尚未布线。命令：`phoenix ratsnest`。 |
| **Gerber X2** | 制造商读取的铜层、阻焊、锡膏和丝印文件格式；X2 增加了层功能等属性。 |
| **Excellon** | 钻孔文件的格式：刀具以及孔的位置（是否金属化）。 |
| **DSN / SES** | 用于外部自动布线器的 Specctra 文件：DSN 是送出的设计，SES 是带回布线结果的会话。命令：`phoenix autoroute`。 |
| **V 形槽（V-cut）** | 拼板中两块电路板之间的一条直线沟槽，便于掰开分离。 |
| **拼板** | 把多块电路板排在同一张板上，带边框、连接桥、定位点和工具孔，以便一次制造和装配。命令：`phoenix panel`。 |
| **邮票孔（mouse bites）** | 两块板之间的连接桥，上面有一排小孔，便于干净地掰断。 |
| **光学定位点（fiducial）** | 一个裸铜的小圆点，贴装机据此确定电路板的位置。 |
| **贴装坐标（pick and place）** | 给贴装机用的文件，记录每个元件的位号、位置、旋转和所在面。命令：`phoenix pnp`。 |
| **钢网（stencil）** | 带开口的薄片，锡膏通过开口涂到焊盘上。命令：`phoenix stencil`。 |
| **BOM（物料清单）** | 电路板的元件清单，按值和封装分组，带数量和价格。命令：`phoenix bom`。 |
| **差分对** | 以两者电压之差传送一个信号的两条走线；必须保持间距、等长和对称。命令：`phoenix pairs`。 |
| **串扰（NEXT、FEXT）** | 信号的一部分出现在相邻走线上；近端（NEXT）在驱动端可见，远端（FEXT）在另一端可见。命令：`phoenix si crosstalk`。 |
| **S 参数／Touchstone** | 网络在各个频率下的反射和传输；Touchstone（.s1p、.s2p）是保存它们的文件。命令：`phoenix rf touchstone`。 |
| **驻波比（VSWR）** | 一个从 1 起的数，表示负载与线路匹配得有多差：1 表示完全匹配。 |
| **蒙特卡洛** | 对电路做多次运行，让数值在容差范围内随机变化；固定种子每次得到相同的表。 |
| **网表** | 列出电路元件及其所连节点的文本，仿真器读取的就是它。命令：`phoenix netlist`。 |
| **试运行** | 除了写入之外什么都做的一次运行：显示将要写入或更改的内容。除非 `--out` 指定新文件，几乎所有命令都是试运行。 |
